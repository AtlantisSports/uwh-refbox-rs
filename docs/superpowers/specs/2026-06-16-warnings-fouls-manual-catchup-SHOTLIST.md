# Refbox User Manual — "Warnings and Fouls" — Screenshot Shot-List (v0.4.2)

For each screen below: **Setup** = how to reach it and what to switch on first; **Capture** = the
callouts/elements the screenshot must show; **Notes** = anything special that must be on-screen.
Entries are in screen order to match the draft.

Run a **current master / v0.4.2 build** for these — the older release will not show the new screens.

---

## 2. In-Game Screen (re-shoot for new callouts)
- Setup: start a game; turn on **Show Behind Time/Delay** and **Alarm Button**; connect to the
  Portal with an event selected; let the game run behind schedule.
- Capture: the red **DELAY** readout, the green/yellow/red Portal dot, and the
  **ALARM** / **HOLD TO TEST** button with its "Or Press/Hold Spacebar" line.
- Notes: the DELAY readout hides during a timeout, so capture during normal play.

## 7. Score Confirmation Screen
- Setup: turn on **Confirm Score at Game End**; reach the end of a game (or add a goal in sudden
  death) so the confirmation appears.
- Capture: the **CONFIRM SCORE — IS THIS SCORE CORRECT?** prompt, the score, the +/- adjust, and
  the **YES** / **NO** buttons.

## 15. Game Info Screen (re-shoot for new callouts)
- Setup: connect to the Portal with an event/game selected.
- Capture: the referee-names list (Chief Ref / Timer / Water Ref 1–3) and the **REFRESH** button.
- Notes: take a second capture in non-Portal mode to show the **Game Block: \<time\>** line.

## 16. Settings Screen (re-shoot — menu changed)
- Setup: open Settings.
- Capture: **GAME OPTIONS**, **APP OPTIONS**, **USER OPTIONS**, **LANGUAGE**, **BACK**.

## 17. Game Options Screen (re-shoot)
- Setup: Settings → Game Options, with **Using UWH Portal** off.
- Capture: the timing options, the **GAME BLOCK** field, the game-number field, **CANCEL**,
  **APPLY**.

## 18. UWH Portal Screen (re-shoot)
- Setup: Settings → Game Options, with **Using UWH Portal** on and an event selected.
- Capture: **EVENT**, **COURT**, game selector, the **UWHPORTAL TOKEN** status (showing **OK**),
  **APPLY**.

## 19. Portal Login Screen (new)
- Setup: tap the **UWHPORTAL TOKEN** status with an event selected.
- Capture: the refbox ID, the login-code keypad, **CANCEL**, **DONE**.

## 20. Parameter Editor Screen (new)
- Setup: Game Options → tap **Half Length** (so the 2 Halves / 1 Period selector appears).
- Capture: the **2 HALVES** / **1 PERIOD** selector, the option name, the **?** button, the time
  keypad, **CANCEL**, **DONE**.
- Notes: a second capture editing **Game Block** with a too-short value would show the red
  warning + disabled **DONE**, if you want to illustrate the warning.

## 21. Parameter Help Screen (new)
- Setup: in the Parameter Editor, tap **?**.
- Capture: the help text and the back control.

## 22. App Options Screen (re-shoot)
- Setup: Settings → App Options.
- Capture: **APP MODE**, **TRACK CAP NUMBER OF SCORER**, **TRACK FOULS AND WARNINGS**,
  **CONFIRM SCORE AT GAME END**, **SHOW BEHIND TIME/DELAY**, **CANCEL**, **Check Version**,
  **APPLY**.

## 23. Updates Screen (new)
- Setup: App Options → **Check Version** (with no game in progress).
- Capture: the current version, **Check for Updates**, the status line, and — ideally — an
  "Update available" state showing the note line and the **Install** button.
- Notes: if a backup exists, also capture the **Revert to Previous Version** button.

## 24. User Options Screen (new)
- Setup: Settings → User Options.
- Capture: **DISPLAY OPTIONS**, **SOUND OPTIONS**, **VIEW MODE**, back.

## 25. Display Options Screen (re-shoot)
- Setup: User Options → Display Options, running **without** a physical LED panel.
- Capture: **STARTING SIDES**, **HIDE TIME FOR LAST 15 SECONDS**, **DISPLAY LAYOUT**,
  **OPEN NEW DISPLAY**, **PLAYER DISPLAY BRIGHTNESS**, the live layout preview, **CANCEL**,
  **APPLY**.
- Notes: with no panel attached, brightness shows greyed and layout/new-display are active; a
  second capture with a panel attached would show the opposite, if useful.

## 26. Sound Options Screen (re-shoot for new callout)
- Setup: User Options → Sound Options, sound enabled.
- Capture: the **ALARM BUTTON** toggle and the **MANAGE REMOTES** button.

## 27. Manage Remotes Screen (new)
- Setup: Sound Options → Manage Remotes, with at least one paired remote.
- Capture: a remote's ID, its **SOUND**, **DELETE**, the **ADD** / **WAITING** button, **CANCEL**,
  **APPLY**.

## 28. Language Screen (new)
- Setup: Settings → Language.
- Capture: the language grid (current highlighted, an "(unverified)" note visible), **CANCEL**,
  **DONE** / **RESTART TO APPLY**.

## 29. Portal Status Detail Screen (new)
- Setup: tap the Portal connection light; have at least one stuck (red) result if possible.
- Capture: the connection light, the colour-coded result list, the scroll control, **BACK**.

## 30. Portal Action Required Screen (new)
- Setup: tap a stuck (red) row on the Portal Status Detail Screen.
- Capture: the game/score/problem text, **FORCE THIS GAME RESULT**, **DISCARD THIS SUBMISSION**,
  **BACK**.

## 31. Confirmation Dialogs (new)
- Setup: trigger one (e.g. change a game setting while a game is running).
- Capture: one representative dialog with its buttons. Note which variant it is.

## 32. BeepTest Main Screen (new)
- Setup: App Options → set **App Mode** to **BEEP TEST**, restart into it.
- Capture: the **TIME / LEVEL / LAP** row, the levels table, **RESET**, **SETTINGS**, **START**.

## 33. BeepTest Settings Screen (new)
- Setup: BeepTest Main → **SETTINGS**.
- Capture: **SOUND SETTINGS**, **EDIT LEVELS**, **APP MODE**, **LANGUAGE**, **BACK**.

## 35. BeepTest Edit Levels Screen (new)
- Setup: BeepTest Settings → **EDIT LEVELS** (test not running).
- Capture: the levels list, the +/- buttons, **NEW**, **DELETE**, **CANCEL**, **SAVE**.

## (34 & 36) BeepTest Sound / Language Screens
- Reuse the main Sound Options (#26) and Language (#28) captures — they are the same controls; no
  separate screenshot needed.
