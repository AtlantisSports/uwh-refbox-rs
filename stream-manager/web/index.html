YouTube allowance

Google gives the YouTube app 10,000 units a day, shared by every court's Stream Manager. Raise the daily allowance here once Google grants more. Give each program a share: 100% with one court, 50% each with two. If one Stream Manager runs more than one court, its share covers all of them. When the share left today won't cover the rest of the day's switches, the chat message and Next game link are skipped; switching itself never stops. Saved with the button below.

Stream Deck live status (Companion)

Shows Hold, the rosters countdown, the game live now and the next game on Stream Deck buttons. Enter Companion's address and port; leave it empty to turn this off. Each court needs four custom variables in Companion (see the setup guide), e.g. sm_court_1_hold, sm_court_1_rosters, sm_court_1_now and sm_court_1_next. Saved with the button below.

Courts
